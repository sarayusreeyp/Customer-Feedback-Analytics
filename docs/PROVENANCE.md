# Provenance and Lawful Data Use

## 1. Overview and Synthetic Provenance
All datasets generated, stored, and processed in this project are **100% synthetically generated** in strict compliance with the **Public Data Guidance / Lawful Use** specification:
- **No confidential, private, or real customer personal data (PII)** was scraped, retrieved, bypassed, or stored.
- Any personal details (names, email addresses, phone numbers) appearing in raw edge cases or anomaly benchmarks are entirely generated by the synthetic data library [Faker](https://github.com/joke2k/faker) (MIT License).
- All feedback texts (reviews, survey comments, support tickets) are generated algorithmically using parameterized templates and deterministic pseudorandom number generators.

---

## 2. Public Reference & Taxonomy Inspiration
Industry-standard frameworks served strictly as public inspiration for entity schema models and feedback categorization:
- **Customer Feedback Taxonomy**: Based on common e-commerce & SaaS customer feedback topic categorizations (Product Quality, UX, Customer Service, Billing, Shipping, etc.).
- **Survey Frameworks**: Modeled after standard public CX metrics:
  - NPS (Net Promoter Score, Reichheld / Bain & Co.)
  - CSAT (Customer Satisfaction Score)
  - CES (Customer Effort Score)

No third-party copyrighted text or proprietary data sets were ingested.

---

## 3. Reproducibility & Determinism
- **Random Seed**: `20261022` (default, parameterizable via `configs/config.yaml` or `--seed`).
- **Reproducibility Guarantee**: The deterministic generation algorithm guarantees identical row counts, IDs, and SHA-256 file checksums across multiple generation passes.
- **Provenance Manifest**: Every run generates a cryptographic manifest at [`data/manifest.json`](file:///C:/Users/pc/OneDrive/Desktop/Customer-Feedback-Analytics/data/manifest.json) recording the ISO timestamp, seed, scale preset, and SHA-256 hashes of all generated datasets.
